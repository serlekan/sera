# Acknowledgements

The first SERA prototype was influenced by the general architect, implementer, and fresh-review pattern demonstrated by Sol Advisor.

The current implementation is independently written and introduces a different core:

- provider-neutral local CLI;
- compact content-hashed repository maps;
- task capsules instead of transcript forwarding;
- adaptive token budgets;
- evidence ledgers;
- automatic verification capture;
- fingerprint-bound multi-stage reviews;
- model-neutral runtime adapters.

Acknowledgement records inspiration without making the project dependent on another repository's implementation.
