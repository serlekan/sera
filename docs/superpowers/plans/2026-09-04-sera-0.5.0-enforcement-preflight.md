## Proven property

The registered Windows API launched the probe and its descendant in an
AppContainer with an exact Bound File System policy. They could read the
synthetic immutable target and write the approved workspace, but could not
change to an ungranted directory, read the governed checkout, read a genuine
separate clone, read another repository, mutate the target, or connect to an
unregistered loopback listener. The target root could not be renamed while the
process ran; a directory-junction substitution was detected before launch; an
external alias was accepted only after host-side same-file identity proof.

This capability result authorizes later implementation work. It does not make
any later T18 run automatically `VERIFIED`; every production run must bind and
recheck its own policy, process, target/workspace, descendant, and post-state
observations.

## Reproduction and diagnostics

The decisive command was:

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
python -m unittest tests.test_runner_enforcement_preflight
```

It ran outside Codex's `codexsandboxoffline` tool account because that account
cannot create nested AppContainer profiles. The actual host run completed all
eight focused tests, including the real OS attack matrix.

During adapter debugging, a null-environment control established that the API
was executable. A too-small explicit environment returned Win32 error 203. The
final bounded environment maps profile and temp variables to the approved
writable workspace and exposes only the staged Python runtime and Windows
system roots. A `FILE_READ_ATTRIBUTES` directory handle did not prevent rename;
the final `GENERIC_READ` handle with `FILE_SHARE_DELETE` omitted did, and the
real after-launch attack confirms it.

The compiler-generated 140-byte golden SBOX fixture was produced with the
public schema using FlatBuffers `25.2.10` as a development-only tool. The
runtime package still has zero dependencies; the repository-owned encoder is
closed to the exact required fields and is checked byte-for-byte plus decoded
slot/default assertions.
